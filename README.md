The `_scripts` directory in this folder (`/home/developers/Lab_5_workspace/`) contains two useful scripts:
- `monitor.sh`: records system utilisation and uptime in `logs/system.log`
- `timesheet.sh`: records labour hours worked in `logs/timesheet.log`

To manually invoke either script, enter the path to the script (e.g. `_scripts/monitor.sh`) at your terminal.

You can check that it worked by reading the logs using the `cat` command (e.g. `cat logs/timesheet.log`) at your terminal.
